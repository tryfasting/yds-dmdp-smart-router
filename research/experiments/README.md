# 실험 노트북 (당시 원본)

2025년 프로젝트 당시 직접 작성하고 실행한 실험 노트북입니다. 공개 레포라서 **셀 출력은 지우고 코드와 마크다운만** 남겼습니다(출력에 고객 문장이 있음). 출력이 있는 원본은 비공개 백업에 보관합니다.

- 2026-10-02에 이름과 폴더를 정리했습니다. 순서는 파일 수정 시각이 아니라 데이터 흐름(무엇을 읽고 무엇을 만드는지)을 기준으로 정했습니다.
- 아래 지표는 원본 노트북 출력에 저장된 값이며, 다시 실행하지 않았습니다.
- **F1 방식이 노트북마다 다릅니다.** Macro F1(두 클래스 평균)과 Hard F1(Hard 클래스 기준)은 서로 비교할 수 없습니다.
- "왜 다음으로 넘어갔는지"는 노트북에 기록이 없습니다. 아래 "다음 시도와 달라진 점"은 코드에서 확인되는 차이만 적었습니다.
- 노트북 안의 데이터 경로(`./data/...`)는 당시 작업 환경 기준이며, 데이터는 공개하지 않습니다.

## 노트북 밖의 관련 코드

- 난이도 라벨링(Gemini 채점) 스크립트와 학습 데이터 구축 코드는 [`../labeling/`](../labeling/)에 있습니다. `02_label_service_log_v4.py`가 교정기록 → `munch_labeled_FINAL`, `03_label_correction_pairs_v3.py`가 말뭉치 → `munch_labeled_RESUMED`를 만듭니다(당시 스크립트 버전 번호와 데이터 순서가 반대입니다).
- 실제 교정 생성과 Judge 평가는 노트북이 아니라 당시 `apps/eval/` 스크립트로 실행했습니다. 근거는 [`docs/provenance.md`](../../docs/provenance.md)에 있습니다.
